3. GIAI THICH CHI TIET TUNG YEU CAU CUA DE BAI (BAI 7)
================================================================================
a) Trigger (Kich hoat Workflow):
   - Trong file `.github/workflows/code-review.yml`, phan khai bao trigger:
     on:
       pull_request:
         branches:
           - main
   - Y nghia: Bat ky khi nao co mot Pull Request duoc mo hoac cap nhat (push thêm commit) huong vao nhanh `main`, GitHub Actions se tu dong tao mot luồng (job) đe chay kiem tra.

b) Inline Feedback (Phan hoi truc tiep tren code):
   - Workflow su dung GitHub Action `dbelyaev/action-checkstyle@v1.5.0`.
   - Khi Maven hoac Checkstyle phat hien vi pham quy tac trong `checkstyle.xml` (vi du: dung `import java.util.*`, thut le 2 cach thay vi 4, thieu khoang trang quanh dau `=`), Action nay se tu dong gui API request đen GitHub PR va tao ngay mot dong "Review Comment" ngai tai dong code bi vi pham.

c) Branch Protection Rules (Bao ve nhanh main):
   - Cach cau hinh tren giao dien Web GitHub Repository:
     Step 1: Vao repository tren GitHub -> Chon tab "Settings".
     Step 2: Chon mục "Branches" o menu ben trai.
     Step 3: Tai phan "Branch protection rules", nhap nút "Add branch ruleset" (hoac "Add rule").
     Step 4: Nhap "Branch name pattern" la: main
     Step 5: Tich chon "Require a pull request before merging".
     Step 6: Tich chon "Require status checks to pass before merging".
     Step 7: Trong phan tim kiem status check, tim va chon tên job hoac checkstyle (vi du: "review" hoac "Build and run tests with Maven").
     Step 8: Tich chon "Require branches to be up to date before merging".
     Step 9: Nhan "Save changes" đe luu rule.
   - Ket qua: Khi mot PR co loi Checkstyle hoac Test that bai, check "review" se bi danh dau x (Failed), va nút "Merge pull request" se bi khoa (vô hieu hoa).

d) Verification (Kiem chung va Test thu quy trinh):
   - Step 1: Tao mot nhanh git moi tu main: `git checkout -b feature/checkstyle-demo`
   - Step 2: Chay lenh `./run.sh break` đe co y đuoc nhap code vi pham Checkstyle vao `App.java`.
   - Step 3: Commit va push nhanh moi len GitHub:
             git add .
             git commit -m "feat: add demo feature with style issues"
             git push origin feature/checkstyle-demo
   - Step 4: Tren GitHub Web, tao Pull Request tu `feature/checkstyle-demo` vao `main`.
   - Step 5: Xac nhan:
             + GitHub Actions tu dong trigger chay job.
             + Bot Checkstyle nhan xet truc tiep (inline comment) vao cac dong bi loi.
             + Nut Merge pull request bi xam (disabled).
   - Step 6: Chay lenh `./run.sh fix` o local, commit va push lai:
             git add .
             git commit -m "fix: resolve checkstyle issues"
             git push origin feature/checkstyle-demo
   - Step 7: GitHub Actions chay lai, tat ca check bao xanh (Passed), nut Merge đuoc mo khoa.


4. HUONG DAN CHAY CAC LENH TRONG RUN.SH VA KET QUA MONG DOI
================================================================================
- `./run.sh all` (Mac dinh):
  + Tu dong kiem tra Java >= 17 va Maven.
  + Build va running du an cu (legacy).
  + Build, checkstyle, test du an moi (fixed).
  + Run ung dung chinh du an moi.

- `./run.sh legacy`:
  + Chi build va chay du an `automated-code-review-legacy`.
  + Ket qua: In ra log legacy "Legacy Application Started" va "Sum result: 15".

- `./run.sh test` (hoac `./run.sh build`):
  + Build du an moi, chay checkstyle validation va JUnit 5 unit tests.
  + Ket qua: In ra log Maven "BUILD SUCCESS" va thông so test pass 1/1.

- `./run.sh run`:
  + Chay ung dung `com.example.App` trong du an moi.
  + Ket qua: Logback in ra dong log co format thoi gian va level INFO.

- `./run.sh break`:
  + Co y ghi lenh vi pham Checkstyle vao `automated-code-review/src/main/java/com/example/App.java`.
  + Sau khi chay lenh nay, neu chay `./run.sh test` thi Maven se bao loi Checkstyle va stop build.

- `./run.sh fix`:
  + Khoi phuc lai code sach chuan Java 17 cho `App.java`.
  + Sau khi chay lenh nay, `./run.sh test` se thanh cong tro lai.

- `./run.sh clean`:
  + Dond dep thu muc `target/` cua ca 2 du an.

- `./run.sh help`:
  + Hien thi danh sach huong dan cac lenh.
